## 🔄 Version Control

### Committing your work
```bash
# Stage your changes
git add src/exercise1/

# Commit with a descriptive message
git commit -m "Complete Exercise 1: [brief description]"

# View your commit history
git log --oneline
```

### Best Practices
- Commit after completing each exercise
- Write clear commit messages
- Don't commit compiled files or binaries
- Use .gitignore for temporary files
