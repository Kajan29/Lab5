## 🔧 Development Guidelines

### Code Organization
- Each exercise has its own dedicated folder
- Include README.md documenting the solution approach
- Use meaningful variable and function names
- Add comments explaining complex logic

### Code Style
- Follow language-specific conventions (PEP 8 for Python, Java conventions, etc.)
- Keep functions small and focused on single tasks
- Use proper indentation and formatting
- Include docstrings/comments for functions

### Before Committing
- [ ] Code runs without errors
- [ ] All requirements are met
- [ ] Code is properly commented
- [ ] README is updated with approach
- [ ] Test cases are verified

## 🚀 Running the Code

### Python
```bash
cd exercise1
python main.py
```

### Java
```bash
cd exercise1
javac Main.java
java Main
```

### C++
```bash
cd exercise1
g++ main.cpp -o main
./main
```
